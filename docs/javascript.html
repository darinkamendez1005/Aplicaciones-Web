Interactividad con JavaScript

Biblioteca técnica de referencia: lógica de programación, manipulación del DOM, escucha de eventos y validación del lado del cliente.

1. Sintaxis Básica y Funciones

JavaScript es el cerebro de la página. Nos permite guardar información temporal y crear "recetas" (funciones) que ejecutan acciones específicas cuando se las llamamos.

A. Variables (El almacenamiento)

// 'const' se usa para declarar variables cuyo valor no va a cambiar
const rolUsuario = "Estudiante";

// 'let' se usa para variables cuyo valor si podra modificarse despues
let calificacion = 85;
calificacion = 100; // Aqui actualizamos el valor de let

B. Funciones (Las acciones)

// Declaramos una funcion para agrupar instrucciones que se ejecutaran juntas
function mostrarMensaje() {
  console.log("Este mensaje se imprime en la consola oculta (F12)");
}

// Llamamos a la funcion para que realice su tarea
mostrarMensaje();

2. Manipulación del DOM (Conectar HTML y JS)

El DOM es la estructura en forma de árbol que crea el navegador. JavaScript lo utiliza para encontrar etiquetas HTML y modificarlas en tiempo real.

A. Seleccionar Elementos (querySelector)

// querySelector busca en el documento el primer elemento con esa clase
const miCaja = document.querySelector('.caja-contenido');

// querySelectorAll busca absolutamente todos los parrafos <p>
const todosLosParrafos = document.querySelectorAll('p');

B. Modificar Clases y Textos

// textContent reemplaza el texto interno del elemento seleccionado
miCaja.textContent = "¡Texto modificado con JavaScript!";

// classList nos permite agregar o quitar clases de CSS de forma dinamica
miCaja.classList.add('clase-nueva'); /* Agrega la clase */
miCaja.classList.remove('clase-nueva'); /* Remueve la clase */

3. Event Listeners (Escuchadores de Eventos)

Los eventos detectan acciones del usuario (como un clic). Usamos addEventListener para vigilar un botón y ordenar qué hacer al presionarlo.

const botonAccion = document.querySelector('#btn-interactivo');

// Vigilamos el evento 'click' sobre el boton
botonAccion.addEventListener('click', function() {
  alert('¡El Event Listener capturó tu clic!');
});

4. Glosario de Métodos Fundamentales

Recopilación de los comandos y propiedades más requeridos en el desarrollo de interfaces dinámicas y validación de formularios.

Interacción con el DOM

  • document.querySelector('selector'): Selecciona el primer elemento que coincida.
  • document.querySelectorAll('selector'): Crea una lista con todos los elementos coincidentes.
  • .innerHTML: Permite insertar texto y etiquetas HTML completas.
  • .textContent: Inserta texto plano (más seguro contra hackeos).

Lógica de Formularios

  • .value: Captura lo que el usuario escribió en un input de texto.
  • e.preventDefault(): ¡Súper importante! Evita que la página se recargue cuando le das al botón de "Enviar" en un formulario.
  • if / else: Permite evaluar condiciones (ej. "Si el input está vacío, muestra error").

Decálogo de Supervivencia en JavaScript

Evita que tu código "truene" siguiendo estas 10 directrices operativas:

  1. La Consola es tu mejor amiga: Si algo no funciona, presiona F12 y revisa la pestaña "Console". Ahí te dirá exactamente en qué línea te equivocaste.
  2. Usa console.log() para todo: Antes de modificar el HTML, usa console.log(variable) para asegurarte de que JS sí está guardando la información correcta.
  3. Diferencia entre let y const: Acostúmbrate a usar siempre const a menos que sepas con absoluta certeza que ese valor va a cambiar en el futuro.
  4. Cuidado con las mayúsculas (CamelCase): JS es estricto. miBoton no es lo mismo que miboton. Siempre escribe la primera letra en minúscula y las siguientes palabras con mayúscula inicial.
  5. El script va al final: Siempre coloca tu etiqueta <script> justo antes de cerrar el </body>. Si lo pones arriba, JS intentará modificar el HTML antes de que cargue y marcará error.
  6. Un error detiene todo: Si tienes un error de sintaxis en la línea 10, todo el código de la línea 11 en adelante jamás se ejecutará. Revisa línea por línea.
  7. Los IDs deben ser únicos: Si usas querySelector('#miboton') y tienes dos botones con ese ID en tu HTML, JS solo le hará caso al primero y el segundo quedará inútil.
  8. Ojo con las comillas: Puedes usar comillas simples 'texto' o dobles "texto", pero nunca las mezcles en la misma frase.
  9. Verifica que el elemento exista: Si intentas hacerle addEventListener a un botón que escribiste mal en el selector, la consola te arrojará el famoso error "Cannot read properties of null".
  10. preventDefault es obligatorio: En los formularios, si no usas e.preventDefault(), la página hará un "parpadeo" y perderás toda la información validada.
