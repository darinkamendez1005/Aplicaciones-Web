Estilos Visuales con CSS3

Biblioteca técnica de referencia: sintaxis, modelo de caja, utilidades Flexbox, Bootstrap y glosario de propiedades.

1. Sintaxis y Reglas Básicas

CSS (Hojas de Estilo en Cascada) se encarga de la presentación. Funciona seleccionando un elemento HTML y aplicándole propiedades visuales dentro de un bloque de llaves.

A. Estructura de una Regla CSS

/* 1. Selector (a quién vamos a modificar) */
h1 {
  /* 2. Propiedad : Valor ; */
  color: #9d4edd;
  text-align: center;
  font-size: 2.5rem;
}

B. Selectores de Clase y de ID

/* Las CLASES usan un punto (.) y se pueden repetir en varios elementos */
.boton-principal {
  background-color: #7928ca;
  border-radius: 8px;
}

/* Los IDs usan un hashtag (#) y deben ser únicos en toda la página */
#cabecera-unica {
  border-bottom: 2px solid #ffffff;
}

C. El Modelo de Caja (Box Model)

Todo en la web es un rectángulo. El modelo de caja define su espaciado interno (padding) y externo (margin).

.caja-ejemplo {
  width: 300px; /* Ancho */
  padding: 20px; /* Espacio hacia ADENTRO */
  border: 1px solid black; /* Borde visible */
  margin: 15px; /* Espacio hacia AFUERA (separa de otros elementos) */
}

2. Maquetación: Flexbox y Bootstrap

En el desarrollo moderno no alineamos cosas con espacios o saltos de línea. Utilizamos sistemas de rejilla (Grid) y cajas flexibles (Flexbox) orientados a dispositivos móviles (Mobile First).

A. Utilidades Flexbox Nativas

/* Centrado perfecto vertical y horizontalmente */
.contenedor-centrado {
  display: flex;
  justify-content: center; /* Eje Horizontal */
  align-items: center; /* Eje Vertical */
}

B. El Grid System de Bootstrap

Bootstrap divide la pantalla en 12 columnas. Usamos clases en el HTML para decirle cuántas columnas ocupar según el tamaño de la pantalla (sm, md, lg).

<!-- Ejemplo de HTML usando el Grid de Bootstrap -->
<div class="container">
  <div class="row">
    <!-- En celular (12 col), en tablet (6 col), en PC (4 col) -->
    <div class="col-12 col-md-6 col-lg-4">Caja 1</div>
    <div class="col-12 col-md-6 col-lg-4">Caja 2</div>
  </div>
</div>

3. Repertorio de Propiedades CSS3

Clasificación de las propiedades más utilizadas para modificar el diseño visual. (Nota: Esta sección está estructurada utilizando contenedores .row y .col-md-6 de Bootstrap para garantizar la adaptabilidad).

Texto y Tipografía

  • color: Color del texto.
  • font-family: Tipo de letra.
  • font-size: Tamaño de la letra (px, rem).
  • font-weight: Grosor (normal, bold).
  • text-align: Alineación (left, center, right).
  • text-decoration: Adornos (underline, none).
  • line-height: Altura entre líneas.

Fondos y Bordes

  • background-color: Color de fondo.
  • background-image: Imagen de fondo (url).
  • border: Grosor, estilo y color (1px solid red).
  • border-radius: Redondeo de esquinas.
  • box-shadow: Sombra exterior de la caja.
  • opacity: Transparencia (0.0 a 1.0).

Modelo de Caja (Box Model)

  • width / height: Ancho y alto.
  • margin: Espaciado exterior.
  • padding: Espaciado interior.
  • max-width: Ancho máximo permitido.
  • box-sizing: border-box: Incluye padding en el ancho total.

Posicionamiento y Flexbox

  • display: flex: Activa el modo flexible.
  • justify-content: Alinea en el eje principal.
  • align-items: Alinea en el eje cruzado.
  • position: absolute: Posición libre respecto al padre.
  • position: fixed: Fijo en la pantalla al hacer scroll.
  • z-index: Orden de profundidad (quién va arriba).

Decálogo de Supervivencia en CSS

Evita dolores de cabeza al diseñar recordando estas 10 reglas de oro:

  1. Borra la Caché (Ctrl + F5): Si guardaste tu CSS y la página no cambia, el navegador te está mostrando una versión vieja guardada en su memoria.
  2. Evita usar !important: Usar !important para forzar un estilo ensucia el código. Es mejor usar selectores más específicos (ej. usar la clase en lugar de la etiqueta).
  3. Cuidado con la herencia: Propiedades como el color y la fuente se heredan de padres a hijos, pero propiedades como el margen o los bordes, no.
  4. Mobile First real: Primero diseña para pantallas pequeñas (ancho 100%). Luego usa @media queries para ajustar las cosas en pantallas grandes.
  5. box-sizing: border-box es tu amigo: Úsalo siempre al inicio de tu CSS. Evita que los elementos se desborden cuando les agregas padding o bordes.
  6. Unidades relativas: Prefiere usar rem, em o % en lugar de px fijos para garantizar que tu sitio sea adaptable y accesible.
  7. No abuses del position: absolute: Rompe el flujo normal del documento. Úsalo solo para superponer cosas específicas (como un botón flotante).
  8. Verifica tus enlaces de fuentes: Si la tipografía no carga, revisa que el enlace de Google Fonts esté correctamente colocado en el <head> de cada HTML.
  9. Nombra bien tus clases: Usa nombres descriptivos (.boton-rojo) y no nombres raros o sin sentido, te ahorrará horas de confusión.
  10. Inspeccionar Elemento (F12): Tu mejor herramienta. Dale clic derecho a la página en Chrome e inspecciona para ver qué regla CSS está fallando en tiempo real.
