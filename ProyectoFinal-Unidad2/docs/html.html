Fundamentos de HTML5

Biblioteca técnica de referencia: estructuras, fragmentos de código, glosario de etiquetas y directrices de desarrollo.

1. Estructuras Básicas de Código

La codificación en HTML requiere la comprensión de patrones estructurales. A continuación, se documentan los bloques fundamentales para la construcción de interfaces.

A. Plantilla Raíz del Documento

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Documento Base</title>
  </head>
  <body>
    <!-- El contenido visual se inserta aquí -->
  </body>
</html>

B. Jerarquía Tipográfica y Párrafos

<h1>Título Principal (Único por página)</h1>
<h2>Subtítulo de Sección</h2>
<p>Este es un bloque de texto que representa un párrafo. Puede contener elementos integrados como <strong>texto en negrita</strong> o <em>texto en cursiva</em>.</p>

C. Estructuración de Listas

<!-- Lista Desordenada (Viñetas) -->
<ul>
  <li>Elemento de lista 1</li>
  <li>Elemento de lista 2</li>
</ul>

<!-- Lista Ordenada (Números) -->
<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
</ol>

D. Hipervínculos e Inserción de Imágenes

<!-- Enlace externo abriendo en nueva pestaña -->
<a href="https://ejemplo.com" target="_blank">Visitar sitio externo</a>

<!-- Imagen con texto alternativo para accesibilidad -->
<img src="ruta/a/la/imagen.jpg" alt="Descripción detallada de la imagen para lectores de pantalla" width="500">

E. Integración Multimedia (Video y Audio)

<!-- Etiqueta de Video con controles interactivos -->
<video controls width="100%">
  <source src="video-presentacion.mp4" type="video/mp4">
  Tu navegador no soporta la etiqueta de video.
</video>

<!-- Etiqueta de Audio -->
<audio controls>
  <source src="pista-audio.mp3" type="audio/mpeg">
</audio>

2. Repertorio Extenso de Elementos HTML5

Clasificación técnica de las etiquetas fundamentales y avanzadas disponibles en el estándar HTML5 para el desarrollo estructural.

Estructura Semántica

  • <header>: Cabecera.
  • <nav>: Navegación principal.
  • <main>: Contenido principal.
  • <section>: Sección genérica temática.
  • <article>: Contenido autónomo.
  • <aside>: Contenido lateral/tangencial.
  • <footer>: Pie de página.
  • <div>: Contenedor en bloque.

Formato de Texto

  • <h1> - <h6>: Niveles de encabezado.
  • <p>: Párrafo.
  • <span>: Contenedor en línea.
  • <strong>: Importancia grave (negrita).
  • <em>: Énfasis (cursiva).
  • <mark>: Texto resaltado.
  • <br>: Salto de línea.
  • <hr>: Regla horizontal.
  • <blockquote>: Cita en bloque.
  • <code>: Fragmento de código.

Formularios y Entradas

  • <form>: Formulario interactivo.
  • <input>: Campo de entrada de datos.
  • <textarea>: Área de texto multilínea.
  • <button>: Botón cliqueable.
  • <select>: Menú desplegable.
  • <option>: Opción dentro del select.
  • <label>: Etiqueta descriptiva.
  • <fieldset>: Agrupación de controles.

Multimedia y Tablas

  • <img>: Imagen estática.
  • <video>: Reproductor de video.
  • <audio>: Reproductor de audio.
  • <iframe>: Marco integrado.
  • <table>: Contenedor de tabla.
  • <tr>: Fila de tabla.
  • <th>: Celda de encabezado.
  • <td>: Celda de datos.

Decálogo de Supervivencia en Desarrollo Web

Directrices operativas para evitar errores críticos durante la maquetación:

  1. Cierre de etiquetas: La omisión de etiquetas de cierre (como </div> o </a>) provoca el colapso estructural del Document Object Model (DOM) y rompe las rejillas CSS.
  2. Jerarquía tipográfica inquebrantable: Debe existir un único <h1> por documento para garantizar el rendimiento SEO. No se deben saltar niveles (por ejemplo, pasar de H2 a H4 sin un H3 intermedio).
  3. Rutas de archivos precisas: La distinción entre rutas relativas (ej. style1.css) y absolutas (ej. https://...) es vital. Un error tipográfico en la ruta genera interfaces carentes de estilos o imágenes rotas.
  4. Atributo 'alt' irrenunciable: Toda etiqueta <img> debe incluir el atributo alt para asegurar la accesibilidad a lectores de pantalla y proveer contexto si el recurso no carga.
  5. Indentación metódica: La anidación de elementos (padres e hijos) debe reflejarse visualmente mediante tabulaciones. Un código sin sangría resulta incomprensible en etapas de depuración.
  6. Comentarios estratégicos: Utilice <!-- Comentario --> para seccionar lógicamente áreas extensas de código (ej. "Inicio del Menú", "Fin del Formulario").
  7. Nomenclatura de archivos: Los nombres de archivos HTML y recursos deben estar íntegramente en minúsculas, sin espacios ni caracteres especiales, utilizando guiones para separar palabras (ej. mi-pagina.html).
  8. Destino de enlaces externos: Incorpore siempre el atributo target="_blank" en enlaces hacia otros dominios para evitar que el usuario abandone prematuramente su sitio web.
  9. Priorización de etiquetas semánticas: Sustituya el uso excesivo de <div> genéricos por contenedores con valor semántico como <main>, <article> y <section>.
  10. Validación continua: Someta el código regularmente al servicio de validación del W3C (World Wide Web Consortium) para detectar anomalías sintácticas inadvertidas.
